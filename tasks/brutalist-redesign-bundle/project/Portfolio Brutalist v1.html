§04 · How the sausage is hand-set Four moves, no Miro, ever
IN 4 moves
—— Listen · Draft · Build · Edit
§04 / Process * Four moves, in sequence [C] No Miro. Ever.
P.01

Listen — until it's boring.

I ask too many questions. I take notes in pencil. I don't build a single screen until I can explain the problem back to you in a sentence you'd put on a t-shirt.

+
P.02

Draft — loudly, on paper.

Twenty sketches before any pixels. Half get binned. I stress-test the flow on a whiteboard before pretending Figma is a design tool.

+
P.03

Build — with engineers in the room.

I hand off in code when I can. Real components, real tokens, real hover states. The design isn't done until it compiles.

+
P.04

Ship, then edit — kindly.

The first shipped version is rarely the last good one. I stick around to prune, sharpen, and kill the darlings nobody else will.
