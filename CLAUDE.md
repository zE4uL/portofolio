# Portfolio

## Project
Personal design portfolio built with Next.js. Showcases selected work, case studies, and design capabilities. Target audience: design hiring managers and collaborators.

## Design System
- **System:** None / custom
- **Enforcement:** None — creative freedom. No DS compliance checks required.
- **Stack:** Next.js (TypeScript), Tailwind CSS, React components in `components/`

## Figma Context
- No fixed Figma file — designs are exploratory and project-specific
- Reference existing `components/` directory for current component patterns before adding new ones

## Rules
- This is a Next.js/React project — use TypeScript and Tailwind patterns consistent with existing code
- Do not enforce DS token rules here
- Prototypes and explorations go in `tasks/[task-name]/prototype/`
- Keep case study content in `docs/research/` as markdown before moving to code
