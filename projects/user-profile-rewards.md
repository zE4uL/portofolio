## What it is
The web user profile inside now.gg / BlueStacks where players see and use the rewards earned through gameplay, in-game offers, deals, and events. Same surface handles **memberships** (e.g., BlueStacks Prime / nowBux) and ongoing programs.

## My role / contribution
- Designed the profile dashboard, rewards inventory, redemption flow.
- Designed the membership upgrade / management surfaces.
- Designed event-program participation flows.
- Tied to the cross-platform payments work and the rewards loop fueled by ML-driven discovery + ad placements.
