## What it is
Mobile games emulated on the BlueStacks App Player needed **native PC controls** — specifically, scroll-wheel weapon switching, which is how PC FPS players intuitively switch guns. The challenge: communicate the exact interaction logic to engineering for a feature that didn't exist in the source mobile game.

Your solution: instead of writing a spec doc, you built a **realistic interactive prototype in Figma using conditional logic** that emulated exactly how the feature should behave in production. Engineering shipped from the prototype as if it were the spec.

## My role / contribution
- Design + prototype + spec, all in one artifact.
- Used Figma's conditional logic (variables, if/then states, interactive components) to simulate scroll-input → weapon-cycle → HUD-update behavior.
- Demonstrated a faster, less-ambiguous way to communicate complex interaction work to engineering.
